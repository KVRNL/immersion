# Immersion

**Audio-reactive OBS overlays & live synced lyrics for streamers - by [KVRNL](https://kvrnl.io).**

Live, time-synced lyrics that pulse and animate to whatever's playing, plus a full kit of
broadcast widgets - spectrum & waveform visualizers, timers, counters, scrolling tickers, and
goal bars. Runs quietly in the Windows system tray and drops straight into OBS as a browser source.

### Features
- Live synced lyrics that pulse to the music
- Spectrum & waveform audio visualizers
- Stream timers, counters, tickers & goal bars
- Runs in the system tray; every overlay is a transparent browser source
- Style and trigger everything live from the dashboard - no need to re-add sources
